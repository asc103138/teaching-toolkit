# teaching-toolkit

> 教學自動化腳本與教材處理工具包

本專案收錄專為教學、備課與班級行政設計的本機自動化腳本、文件批次轉換與處理工具。

---

## 📌 專案特色
- **教學行政自動化**：簡化日常例行事務、名冊排版與表件產出。
- **教材格式轉換**：支援文件、投影片與互動小工具的結構化處理。
- **隱私與個資保護**：遵守學生資料去識別化規範，金鑰與機密設定不外流。

## 📂 專案結構
```text
teaching-toolkit/
├── AGENTS.md        # Agent 核心規範與指引
├── ANTIGRAVITY.md   # 精簡入口導覽
├── handoff.md       # 多 Agent 交接紀錄
├── rdq/             # RDQ 需求探索規格卡
├── scripts/         # 自動化腳本集合
└── README.md        # 專案說明文件
```
